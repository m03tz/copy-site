<task type="auto">
  <name>Task 1: Pregnancy utility functions and server actions</name>
  <files>lib/utils/pregnancy.ts, lib/actions/pregnancies.ts</files>
  <action>
**1. Create `lib/utils/pregnancy.ts`** with three pure functions:

- `getGestationalWeek(lmpDate: string): number | null` — Calculate current gestational week from LMP date. `Math.floor((today - lmp) / (7 * 86400000))`. Return `null` if week < 0 or > 42. Set both dates' hours to 0,0,0,0 before comparison for date-only math.

- `getDaysUntilDue(expectedDueDateStr: string): number` — Days from today to due date. Negative means overdue. Zero-out hours on both dates.

- `isApproachingDueDate(pregnancy: { status: string; expected_due_date: string }): boolean` — Returns true only if status === 'active' AND getDaysUntilDue returns 0-14 inclusive.

**2. Create `lib/actions/pregnancies.ts`** following the exact pattern from `lib/actions/medical-records.ts`:

- `'use server'` directive at top
- Import `revalidatePath`, `createClient`, `z`
- Copy the `getDoctorId` helper from medical-records.ts (same pattern)
- Doctor-only role check on ALL actions (check `profile.role === 'doctor'`)

Three server actions:

**a) `createPregnancy(formData: FormData)`**
- Zod schema: `{ patient_id: z.string().uuid(), lmp_date: z.string().min(1), notes: z.string().optional() }`
- Extract fields from FormData
- Doctor role check
- Get doctorId via getDoctorId helper
- Insert into `pregnancies` table with `{ patient_id, doctor_id: doctorId, lmp_date, notes }` — do NOT include `expected_due_date` (GENERATED ALWAYS) or `status` (defaults to 'active')
- `revalidatePath('/doctor/patients/' + patient_id)`
- Return `{ success: true }` or `{ error: string }`

**b) `updatePregnancyStatus(formData: FormData)`**
- Zod schema: `{ pregnancy_id: z.string().uuid(), status: z.enum(['active', 'delivered', 'miscarriage', 'ectopic']) }`
- Doctor role check
- Update `pregnancies` set `status` where `id = pregnancy_id`
- Need to fetch `patient_id` from the pregnancy row first (for revalidatePath)
- `revalidatePath('/doctor/patients/' + patient_id)`
- Return `{ success: true }` or `{ error: string }`

**c) `addMeasurement(formData: FormData)`**
- Zod schema:
  ```
  {
    pregnancy_id: z.string().uuid(),
    measured_at: z.string().min(1),
    gestational_week: z.coerce.number().int().min(1).max(42).optional(),
    weight_kg: z.coerce.number().positive().optional(),
    blood_pressure: z.string().optional(),
    fetal_heartbeat: z.coerce.number().int().min(60).max(200).optional(),
    notes: z.string().optional()
  }
  ```
- Doctor role check
- Extract from FormData — for optional numeric fields, check if the string is empty before including (empty string -> skip field, not 0)
- Insert into `pregnancy_measurements`
- Fetch parent pregnancy's patient_id for revalidatePath
- `revalidatePath('/doctor/patients/' + patient_id)`
- Return `{ success: true }` or `{ error: string }`

IMPORTANT: gestational_week in measurements is doctor-entered, NOT auto-calculated. The form accepts whatever week the doctor says the measurement was taken at.

IMPORTANT: For optional numeric FormData fields (gestational_week, weight_kg, fetal_heartbeat), check `if (value && value !== '')` before passing to Zod — empty form fields are empty strings, not nullish. Use `z.coerce.number()` with `.optional()` and handle the empty-string-to-undefined conversion before Zod parsing.

IMPORTANT: blood_pressure is a single TEXT field (e.g., "120/80"), not separate systolic/diastolic.
