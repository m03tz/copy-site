  <action>
Create `lib/actions/schedule.ts` with 'use server' directive. Follow the established pattern from `lib/actions/accounts.ts`: validate with Zod, check auth + role, Supabase operation, revalidatePath.

**Helper: getDoctorId()**
Query `profiles` where `role = 'doctor'` and return the single doctor's ID. This is a single-doctor clinic. If no doctor found, return `{ error: 'No doctor found' }`.

**Action 1: upsertScheduleDay(formData: FormData)**
- Validate: day_of_week (number 0-6), start_time (HH:MM regex), end_time (HH:MM regex), slot_duration_minutes (number 10-120, default 30)
- Auth check: only doctor role
- Validate start_time < end_time
- Upsert into `doctor_schedule` with `onConflict: 'doctor_id,day_of_week'`. Set is_active = true.
- `revalidatePath('/doctor/schedule')`
- Return `{ success: true }` or `{ error: string }`

**Action 2: deleteScheduleDay(dayId: string)**
- Auth check: only doctor role
- Delete from `doctor_schedule` where id = dayId
- `revalidatePath('/doctor/schedule')`
- Return `{ success: true }` or `{ error: string }`

**Action 3: addHoliday(formData: FormData)**
- Validate: holiday_date (YYYY-MM-DD), reason (optional string)
- Auth check: only doctor role
- Insert into `doctor_holidays`
- Handle unique constraint violation (23505) with friendly message "Holiday already exists for this date"
- `revalidatePath('/doctor/schedule')`
- Return `{ success: true }` or `{ error: string }`

**Action 4: deleteHoliday(holidayId: string)**
- Auth check: only doctor role
- Delete from `doctor_holidays` where id = holidayId
- `revalidatePath('/doctor/schedule')`
- Return `{ success: true }` or `{ error: string }`

Use `createClient` from `@/lib/supabase/server`. Import types from `@/lib/types/database`.

For the doctor role check pattern:
```typescript
const supabase = await createClient()
const { data: { user } } = await supabase.auth.getUser()
if (!user) return { error: 'Unauthorized' }

const { data: profile } = await supabase
  .from('profiles')
  .select('role')
  .eq('id', user.id)
  .single()

if (!profile || profile.role !== 'doctor') {
  return { error: 'Only the doctor can manage the schedule' }
}
```
