Create `app/[locale]/patient/appointments/page.tsx` as a Server Component.

**Data fetching:**
- Get authenticated user via Supabase: `const supabase = await createClient()` then `supabase.auth.getUser()`
- Query appointments for this patient: `supabase.from('appointments').select('*').eq('patient_id', user.id).order('scheduled_start', { ascending: false })`
- RLS automatically filters to only this patient's appointments (policy: "Patients view own appointments" WHERE patient_id = auth.uid())

**Page layout:**
- Page title: `t('myAppointments')` from `getTranslations('appointments')`
- `Tabs` component with two tabs:
  - `t('upcoming')`: Filter appointments where `scheduled_start > new Date().toISOString()` AND `status !== 'cancelled'`
  - `t('past')`: Filter appointments where `scheduled_start <= new Date().toISOString()` OR `status` in ('completed', 'cancelled')

**Each tab content:**
- If no appointments in category: show `t('noAppointments')` with muted text styling
- If appointments exist: render as `Card` list (not table -- more mobile-friendly for patient portal)
- Each appointment card shows:
  - Date: `format(parseISO(appointment.scheduled_start), 'EEEE, MMMM d, yyyy')` (full day name for clarity)
  - Time: `format(parseISO(appointment.scheduled_start), 'h:mm a')` to `format(parseISO(appointment.scheduled_end), 'h:mm a')`
  - Appointment type: `t('type.' + appointment.appointment_type)`
  - Status: `StatusBadge` component (imported from `@/components/appointments/status-badge`)
  - If cancelled: show cancellation reason in muted text below status
  - If has notes: show notes
- Cards use `Card`, `CardHeader`, `CardContent` from shadcn/ui
- Use `Separator` between date/time and details

**Styling:**
- Cards in a single column layout with gap-4
- Each card has clean medical aesthetic (subtle border, rounded corners)
- Use `text-start` for RTL compatibility
- Use `ms-*`/`me-*` for margins
- Date/time values: wrap in `<span dir="ltr">` if needed for correct digit rendering in RTL
- Use `getTranslations('appointments')` for server-side labels

**No action buttons:**
- Patient view is explicitly read-only
- No cancel, edit, or book buttons
- This is intentional per project decision: "Patient role is read-only"

**Imports:**
- `createClient` from `@/lib/supabase/server`
- `getTranslations` from `next-intl/server`
- `format`, `parseISO` from `date-fns`

- `Card`, `CardHeader`, `CardContent` from `@/components/ui/card`
- `Tabs`, `TabsList`, `TabsTrigger`, `TabsContent` from `@/components/ui/tabs`
- `Separator` from `@/components/ui/separator`
- `Badge` from `@/components/ui/badge` (if needed for type display)
