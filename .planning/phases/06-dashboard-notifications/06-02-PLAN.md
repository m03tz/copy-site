**1. Create `lib/actions/dashboard.ts`** — Server action for day navigation

```typescript
'use server'
```

Create `getDayAppointments(date: string)` server action:
- Parameter: `date` as `'yyyy-MM-dd'` string
- Auth check: get user via `supabase.auth.getUser()`, return `{ error: 'Unauthorized' }` if not authenticated
- Build date range: dayStart (00:00:00.000) to dayEnd (23:59:59.999) from the date string
- Query appointments:
  ```
  supabase.from('appointments')
    .select('id, patient_id, scheduled_start, appointment_type, status, patient:profiles!appointments_patient_id_fkey(full_name_ar, full_name_en)')
    .gte('scheduled_start', dayStart.toISOString())
    .lte('scheduled_start', dayEnd.toISOString())
    .in('status', ['scheduled', 'confirmed'])
    .order('scheduled_start', { ascending: true })
  ```
- Return type: `{ appointments?: Array<{id, patient_id, scheduled_start, appointment_type, status, patient: {full_name_ar, full_name_en} | null}>; error?: string }`
- Filter by `status in ('scheduled', 'confirmed')` — do NOT show cancelled appointments (per research Pitfall 6)
